about this project

PassGen is an open-source password generator built to be small, fast, and honest about what it does: it creates cryptographically random passwords in your browser and never sends them anywhere. The source is fully public on GitHub — read it, fork it, or run it locally in under a minute.

Features

  • Cryptographically secure randomness (Web Crypto API)
  • Adjustable length and character sets
  • Live entropy and strength estimate
  • Ambiguous-character exclusion
  • One-click copy, zero data collection

Built with

  • Vanilla HTML, CSS & JavaScript
  • No build step, no dependencies
  • Deployed with GitHub Pages
  • Continuous checks via GitHub Actions
