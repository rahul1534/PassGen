# EFF Large Wordlist

PassForge bundles the EFF Large Wordlist for passphrase generation.

- Source: https://www.eff.org/deeplinks/2016/07/new-wordlists-random-passphrases
- File: https://www.eff.org/files/2016/07/18/eff_large_wordlist.txt
- License: Creative Commons Attribution 3.0 (CC BY 3.0)
- Words: 7,776

The bundled `words.txt` contains one word per line extracted from the official EFF list.
